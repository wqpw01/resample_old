## 论文发布整理

- 公开入口强制手工 `.seg.nrrd` 模式，删除 TotalSegmentator 自动入口、旧 Slicer 血管重建入口和二维裁剪旁路。
- 病例配置只接受外部 `artery`/`vein` 两类原重建血管；旧 `portal`/`hepatic` 配置不兼容。
- 移除仓库外 `2021.py` 依赖。`index` 步骤直接校验 `gallery.jsonl` 并生成 `library_summary.json`。
- 质量阈值集中为严格 `black_ratio > 0.60`；恰好 60% 保留。
- 零度基准面可视化迁入 `paper_figures/`，取消病例 2、400 点和固定姿态总数硬编码。
- 废弃实验脚本、真实服务器配置和执行计划从公开工作树删除，历史仍可由 Git 查阅。

## 兼容性

- 旧配置中的 `registration_module_path`、自动预处理键和 `portal/hepatic` 血管对会被拒绝。
- 缺少当前手工器官/EUS 血管 schema 的旧 Gallery 不可续写，必须使用新的输出根目录。
- `gallery/gallery.jsonl` 继续作为下游检索的稳定交换格式；外部检索系统自行完成对象适配。
- 病例采样点数和最终姿态数由实际几何决定，不作为跨病例固定常量。
- 当前正式设计输出新增逐采样点计划和精确去重来源姿态 ID；旧设计库仍可只读审计，但不可伪装为当前设计续写。
