# 零度基准面显示开关设计

## 目标

在离线交互可视化网页顶部增加一个全局“显示 0° 基准面”复选开关，使用户可以在不隐藏采样点、器官网格或局部坐标轴的情况下，单独控制全部零度基准面。

## 控制范围

- 开关默认选中，保持当前网页首次打开时显示全部零度面的行为。
- 关闭时同时隐藏五类器官的零度面填充和四边框；打开时同时显示这些 trace。
- 局部 x/y/z 轴、采样点和器官网格不属于零度面开关的控制范围。
- 静态 PNG、PLY、CSV、JSON 及正式重采样结果不改变。

## 与既有控件协同

- “All”和“Hide organ meshes”保留当前开关状态，只改变各自原本负责的图层。
- “Points only”显式关闭零度面，并同步取消复选框。
- “Points + zero planes”显式打开零度面，并同步选中复选框。
- 用户通过图例形成部分器官零度面可见、部分不可见时，复选框显示为 `indeterminate`；再次点击后统一全部零度面的状态。

## 实现方式

为 Plotly 图使用稳定的 div id，并在离线 HTML 内嵌少量原生 JavaScript。脚本依据 Python 生成的 trace 角色索引控制 `planes` trace，不依赖 trace 名称、器官顺序、网络资源或额外 JavaScript 库。控件通过标准 `<input type="checkbox">` 与 `<label>` 注入页面工具栏；监听复选框、Plotly 预设按钮和 trace 可见性事件以保持状态一致。

## 验证

- 单元测试固定开关文字、稳定 div id、默认选中状态以及所有 `planes` trace 索引均进入控制脚本。
- 既有离线、非空、四视图和坐标测试继续通过。
- 使用真实 400 条零度记录重新生成桌面交付包，核对记录数、器官计数、RAS 元数据和 SHA-256。
- 在浏览器中验证开关关闭/打开、预设同步和图例部分可见三种交互；确认页面离线可用且采样点、器官网格、局部轴不被误隐藏。
