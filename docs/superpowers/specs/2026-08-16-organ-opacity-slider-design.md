# 器官网格不透明度滑块设计

## 背景

采样点与零度基准面离线交互网页当前将五类目标器官网格的不透明度固定为 `0.22`。肝脏前后表面与采样点同时显示时，背面采样点容易透过前表面出现，单一固定值也无法兼顾外表面检查与内部空间关系观察。

本次只改可视化网页的显示控制，不改变采样点选择、零度基准面、器官网格几何或任何重采样结果。

## 用户界面

在交互网页顶部现有工具栏内，保留“显示 0° 基准面”复选框，并增加一个全局器官网格不透明度滑块：

- 文本标签：`器官网格不透明度`。
- 最小值：`0.10`。
- 最大值：`1.00`。
- 步长：`0.05`。
- 默认值：`0.70`。
- 当前值以百分比显示，默认显示 `70%`。

工具栏保持独立于 Plotly 图表，不得遮挡标题、预设按钮或图例。窄屏下允许工具栏内容换行，但不得与图表重叠。

## 交互语义

滑块只更新角色为 `organ_mesh` 的五条 Plotly `Mesh3d` 轨迹的 `opacity` 属性：

- 五类器官网格始终使用同一个滑块值。
- 采样点、零度基准面填充、零度面边框和局部坐标轴不受影响。
- 滑块变化不得改变任何轨迹的 `visible` 状态。
- 图例或预设隐藏器官网格时，滑块值仍保留；器官网格再次显示时继续使用保留值。

现有预设继续负责可见性：

- `All`：显示器官网格、采样点、零度基准面和局部轴，器官网格使用当前滑块值。
- `Points only`：显示器官网格和采样点，隐藏零度基准面、边框及局部轴，器官网格使用当前滑块值。
- `Points + zero planes`：隐藏器官网格，显示采样点、零度基准面和局部轴，不重置滑块值。
- `Hide organ meshes`：隐藏器官网格，不重置滑块值。

现有“显示 0° 基准面”复选框的行为保持不变。

## 输出边界

重新生成正式桌面可视化包时，交互 HTML 使用默认不透明度 `0.70` 并包含滑块。以下内容不得因本功能改变：

- 400 个采样点及其位姿记录。
- `sampling_points.ply`、`zero_planes_edges.ply`、`zero_planes_faces.ply`。
- CSV、JSON 中的几何与来源信息。
- 四张静态 PNG；静态器官网格 alpha 继续保持 `0.14`。
- 重采样 Gallery、CT 图像、血管图像、器官标签和特征。

## 验证要求

1. 测试先固定滑块范围、步长、默认值和五条器官网格轨迹索引。
2. 浏览器加载后滑块显示 `70%`，五类器官网格 opacity 均为 `0.70`。
3. 拖动滑块后，只有五条 `organ_mesh` 轨迹的 opacity 改变，其他轨迹属性不变。
4. 依次操作四个预设，确认器官网格可见性符合约定且滑块值不被重置。
5. 正式 400 点页面中复核工具栏无重叠、采样点计数和器官计数不变。
6. 正式输出目录执行完整 SHA-256 校验，全项目测试与 Python 编译检查通过。
