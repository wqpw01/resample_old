# 器官网格显示控制设计

## 背景

采样点与零度基准面离线交互网页原先将五类目标器官网格的不透明度固定为 `0.22`，并为性能随机保留每个器官最多 12,000 个三角面。肝脏前后表面与采样点同时显示时，背面采样点容易透过前表面出现；随机抽面也会形成可见缺口，不能用于严格判断点与器官表面的关系。

本次只改可视化网页的显示控制，不改变采样点选择、零度基准面、器官网格几何或任何重采样结果。

## 用户界面

在交互网页顶部现有工具栏内，保留“显示 0° 基准面”复选框，并增加以下全局控制：

1. 器官网格不透明度滑块：

- 文本标签：`器官网格不透明度`。
- 最小值：`0.10`。
- 最大值：`1.00`。
- 步长：`0.05`。
- 默认值：`0.70`。
- 当前值以百分比显示，默认显示 `70%`。

2. `使用不透明连续表面` 复选框：

- 默认不勾选。
- 勾选时使用原始器官网格的全部三角面并强制 opacity 为 `1.00`。
- 勾选时禁用不透明度滑块，百分比显示 `100%`。
- 取消勾选时恢复性能表面、之前保存的滑块值和对应百分比。

工具栏保持独立于 Plotly 图表，不得遮挡标题、预设按钮或图例。窄屏下允许工具栏内容换行，但不得与图表重叠。

## 交互语义

滑块只更新角色为 `organ_mesh` 的五条 Plotly `Mesh3d` 轨迹的 `opacity` 属性：

- 五类器官网格始终使用同一个滑块值。
- 采样点、零度基准面填充、零度面边框和局部坐标轴不受影响。
- 滑块变化不得改变任何轨迹的 `visible` 状态。
- 图例或预设隐藏器官网格时，滑块值仍保留；器官网格再次显示时继续使用保留值。

连续表面复选框复用同一组五条 `organ_mesh` trace，不增加第二套器官网格 trace：

- 性能模式保留每个器官最多 12,000 个确定性随机三角面。
- HTML 额外内嵌五类原始网格的全部 `i/j/k` 面索引。
- 初次加载保存性能模式的 `i/j/k`；勾选时将五条 trace 的面索引替换为完整索引，取消时恢复保存值。
- 切换面索引或 opacity 不得改变任何 trace 的 `visible` 状态。
- 完整索引来自手工 `.seg.nrrd` 预处理得到的原始器官网格，保留其全部连通分量；本功能不承担内部小壳层清理。

现有预设继续负责可见性：

- `All`：显示器官网格、采样点、零度基准面和局部轴，器官网格使用当前滑块值。
- `Points only`：显示器官网格和采样点，隐藏零度基准面、边框及局部轴，器官网格使用当前滑块值。
- `Points + zero planes`：隐藏器官网格，显示采样点、零度基准面和局部轴，不重置滑块值。
- `Hide organ meshes`：隐藏器官网格，不重置滑块值。

现有“显示 0° 基准面”复选框的行为保持不变。

## 默认视角

默认观察方向、RAS 坐标轴和 `aspectmode=data` 保持不变，只缩短相机距离：

- 原相机 eye：`(1.45, -1.55, 1.05)`。
- 新相机 eye：`(1.05, -1.12, 0.76)`。

新视角使模型默认视觉尺寸约增大 38%，用户仍可用 Plotly 原生交互继续旋转和缩放。

## 输出边界

重新生成正式桌面可视化包时，交互 HTML 使用默认不透明度 `0.70`，包含滑块和连续表面复选框，并内嵌约 50.9 万个原始器官三角面索引。HTML 文件增大属于预期结果，但不得复制器官顶点或改变现有 trace 数量。以下内容不得因本功能改变：

- 400 个采样点及其位姿记录。
- `sampling_points.ply`、`zero_planes_edges.ply`、`zero_planes_faces.ply`。
- CSV、JSON 中的几何与来源信息。
- 四张静态 PNG；静态器官网格 alpha 继续保持 `0.14`。
- 重采样 Gallery、CT 图像、血管图像、器官标签和特征。

## 验证要求

1. 测试先固定滑块范围、步长、默认值、连续表面控件、默认相机和五条器官网格轨迹索引。
2. 浏览器加载后滑块显示 `70%`，五类器官网格 opacity 均为 `0.70`。
3. 拖动滑块后，只有五条 `organ_mesh` 轨迹的 opacity 改变，其他轨迹属性不变。
4. 勾选连续表面后，五条器官网格 trace 的面数分别等于原始模型，opacity 均为 `1.00`，滑块禁用且 visible 不变；取消后完整恢复性能面数和滑块值。
5. 依次操作四个预设，确认器官网格可见性符合约定且两个器官控制状态均不被重置。
6. 正式 400 点页面中复核默认相机、工具栏无重叠、模型无裁切、采样点计数和器官计数不变。
7. 正式输出目录执行完整 SHA-256 校验，全项目测试与 Python 编译检查通过。
