# 核心设计对齐规格

## 规范层级

1. 唯一核心设计基准是 `基于目标器官的采样方法-20260806.docx`，SHA-256 为 `4b27aee1a6db1680e501f17bd3492a571bd169c0bf7004d79b4a512d929cc53b`。
2. 读取方式为保留 `w:ins`、排除 `w:del` 的现行修订视图。
3. 本文件记录用户对核心文件歧义及未定义运行参数的明确确认。项目 README 和桌面说明文档不是规范来源。

## 坐标与筛选

- 输入 CT 和同源网格显式声明为 LPS；所有内部几何计算、导出 PLY、JSONL 和检索位姿统一使用 RAS 毫米物理坐标。
- 胃、食管和十二指肠候选点沿表面外法线发出最长 100 mm 的有向射线，仅保留命中 11 个目标结构之一的点。
- 目标结构为左右肾上腺、主动脉、胆囊、下腔静脉、左右肾、胰腺、门静脉和脾静脉、脾脏、肝脏；不含食管、胃和十二指肠。
- 食管有效段从原始食管最小 z 到肝脏最大 z；将整个有效段向下平移一个完整 z 跨度，合并和去重后采样。
- 胰腺、肝脏一、肝脏二、十二指肠球部和其余部按核心文件现行 RAS 公式筛选。肝脏一左界使用 `liver_x_min + 20 mm`；“在两值之间”使用闭区间，显式 `<`/`>` 使用开边界。
- 并列极点用 `rtol=0, atol=1e-6 mm` 识别极值平台并取 RAS 质心。

## 采样与中心线

- 配置点数保持胃 1000、肝 500、胰 500、十二指肠球部 500、其余部 500、食管 200，语义为各区域上限。
- 每个区域独立使用确定性半径约束 FPS；任意两个实际采样点的 RAS 欧氏距离至少为 10 mm。不同区域之间不执行 10 mm 删除。
- 十二指肠网格以 1 mm 体素化后骨架化；允许逐次清理不超过 5 mm 的最短终末毛刺，清理后必须得到单连通、2 端点、0 分叉的单路径，否则终止病例。
- 靠胃最近的端点是近端，中心线按近端到远端排序；局部切向使用弧长前后各 5 mm 的弦，端部使用单侧 10 mm 弦。
- 不能唯一构造 0 度坐标系的候选在 FPS 前剔除并从其他合法候选补选；区域没有合法候选时终止病例。

## 局部坐标与旋转

- 局部坐标为右手系。`+x` 是探头前进方向；胃和食管使用外法线，肝和胰补充区使用内法线。
- 普通 0 度面由原始食管最小 z 极值平台质心到采样点的连线与 `+x` 构成；投影后的连线为 `+y`，`+z = x cross y`。
- 十二指肠 0 度面严格由最近中心线点的切向与该点到采样点的径向构成；表面外法线投影到该平面后作为 `+x`，再令 `+y = z cross x`。
- 方形边长为 100 mm，采样点是底边中心。局部内禀旋转顺序为 `Z(偏航) -> Y(俯仰) -> X(滚动)`，矩阵为 `B' = B Rz Ry Rx`。
- 滚动和俯仰均取 `{-5, 0, +5}` 度。普通、十二指肠球部、胰腺特殊区偏航分别取 `[-30, +30]`、`[-90, +90]`、`[-120, +30]` 度，步长均为 5 度。
- 三轴做完整笛卡尔积，因此每点姿态数分别为 117、333、279。仅按四顶点 `rtol=0, atol=1e-9 mm` 合并完全相同姿态。

## 运行参数与输出

- 用户批准保留 300 x 300 输出、三次 CT 插值、WL 40 HU、WW 400 HU、FOV 外填充值 -1000 HU、现有质量筛选和 `excluded_fov` 策略。
- 上述运行参数不是核心文件条款，必须在配置和运行元数据中明确记录，不能标为核心设计要求。
- 所有姿态输出记录来源区域、偏航策略、三轴角度、局部坐标轴、目标命中证据、坐标系、设计文件哈希和构建 Git commit。
- 新结果写入独立目录，不覆盖历史结果。姿态流式生成和分批渲染；完整 manifest 的四种状态必须互斥且合计等于姿态总数。
