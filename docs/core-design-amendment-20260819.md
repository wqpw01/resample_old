## 修订一：采样点必须位于主器官外表面

胃、肝脏、胰腺、十二指肠和食管原始段的候选点必须来自器官主体的外表面。运行时从现有完整器官网格派生只读采样源视图：先焊接几何重合顶点，修复并验证闭合壳层的三角面绕序和外向法线，再只保留绝对包围体积最大的闭合连通壳层。内部空腔壳层、离散小壳层和开放面片均不得进入候选池。

完整器官网格及预处理产物不得因本修订被改写；目标射线、解剖极值和十二指肠中心线继续使用完整网格。运行元数据必须记录采样源原分量数、保留面数、丢弃面数和所选包围体积。采样后必须同时校验点坐标和外向法线均来自允许的主外壳，不能通过内部壳层、离散小壳层或悬空点补足数量。

食管按基准设计 P019 复制并向下延伸的候选段属于设计定义的虚拟外表面；其点必须来自食管主外壳的刚性平移副本，法线方向保持不变。

## 修订二：数量不足时保持几何约束

各器官配置点数继续作为上限。主外壳候选池通过既有解剖规则后，重新执行完整的确定性最远点采样，最小 RAS 欧氏间距保持 10 mm。该间距是同一器官合并点集的硬约束；十二指肠球部优先采样，余部必须先排除距球部已选点不足 10 mm 的候选。若非空合法候选池无法达到配置上限，输出实际可达到的数量，并在完整建库运行元数据中记录请求数、实际数和短缺数；不得降低间距或从非法表面补点。若某个必需区域没有任何合法候选，则视为输入或几何错误并立即失败，不得静默输出空结果。

## 修订三：肝脏二区偏航范围

肝脏二区偏航角调整为 `-60°..+60°`，端点包含，步长保持 `5°`。任何来源标记包含 `liver_region_two` 的点均执行该策略，包括 `liver_region_one+liver_region_two` 重叠点。肝脏一区独有点以及基准设计中的其他普通区域仍使用 `-30°..+30°/5°`；十二指肠球部和胰腺特殊区仍使用 `-120°..+30°/5°`。

滚动角、俯仰角、旋转顺序、旋转中心、方形尺寸、插值、质量筛选以及其他采样区域规则均保持不变。肝脏二区每点姿态数因此由 `13 x 13 x 19 = 3211` 调整为 `25 x 13 x 19 = 6175`。

## 正式运行固定参数

除病例输入路径、六类正整数采样点数上限、病例确认的十二指肠中心线端点、并发数和 GPU batch 等资源参数外，当前设计运行不得自行改变以下值：目标射线长度 `100 mm`、射线 batch `2048`、FPS seed `0`、主外壳合并点集最小间距 `10 mm`、中心线体素间距 `1 mm`、切向窗口 `10 mm`、末端毛刺上限 `5 mm`、方形边长 `100 mm`、输出 `300 x 300`、三次 B-spline、WL `40 HU`、WW `400 HU`、FOV 外填充值 `-1000 HU`。

质量筛选固定为黑色阈值 `50`、黑色比例严格大于 `0.60` 才按比例拒绝、直线最小对角线比例 `0.70`、黑边侧最小比例 `0.90`、有效侧最大黑色比例 `0.10`。六类采样点数均须配置为正整数上限；胃、肝、胰腺、十二指肠球部、十二指肠余部和食管任一必需区域零合法候选或零实际点均必须失败。

## 验收要求

- 输出的原始器官采样点及其法线全部来自相应主外壳；采样点 PLY 以 `double` 属性和六位小数写出，写出后的点坐标容差不超过 `2e-6 mm`。
- OBJ、PLY、STL 输入均须通过闭合性、绕序一致性和外向法线校验；肝脏、胰腺等多壳层输入不得从非主壳层选点。
- `actual_count <= requested_count`，且同一器官合并点集内任意两点距离不小于配置的 10 mm（运行时数值容差 `1e-9 mm`；六位小数 PLY 审计容差 `5e-6 mm`）。
- 肝脏二区及其重叠点的 yaw 集合严格等于 `{-60,-55,...,55,60}`。
- 完整建库运行元数据必须记录本修订文件及 SHA-256、主外壳派生统计、采样短缺统计、逐采样点计划、完整角集合以及去重后姿态计划的流式摘要。逐采样点计划必须记录点坐标、外向法线、未旋转局部基准轴、来源区域和偏航策略，并与采样点 PLY 的坐标、法线及行序一致；精确去重记录必须保留每个被合并来源姿态的原始 ID。
- 输出审计不得信任结果自行缩短的角集合或自行声明的未旋转局部基准轴。审计必须按逐采样点计划复核完整的 roll/pitch/yaw 笛卡尔积，并从已核验输入独立重建基准轴：普通器官使用完整食管网格下缘极点，十二指肠使用完整十二指肠网格和完整胃网格重新提取中心线，外向法线使用真实允许表面的匹配顶点法线。审计须据此核对每条保留姿态的四顶点和局部轴；将根清单姿态 ID 与精确去重来源姿态 ID 合并后验证无缺失、无重复，并确认每个被合并姿态的重建四顶点与承载它的保留姿态在 `1e-9 mm` 容差内相同。根清单与各状态清单的完整记录摘要也必须一致。
- 输出审计必须重新计算 `input_provenance` 中五个采样器官网格的 SHA-256，以同一坐标约定重建最大闭合主外壳，并再次核对逐采样点计划的坐标和外向法线；食管允许表面必须由真实主外壳及按 P019 重建的平移段共同组成。仅修改 PLY、逐点计划和 manifest 使其相互自洽，不能替代真实输入外壳证据。
- 使用人工十二指肠中心线端点时，正式审计必须读取输出目录外的原病例 YAML，并将其中经病例确认的 RAS 近端、远端与运行元数据逐坐标比对；不得把输出元数据自报端点作为信任根。审计还必须从稳定协议字段复算 `resume_protocol_sha256`，摘要缺失、格式错误或不一致均须失败。
- P030 精确去重必须保留优先级不高于每个被合并来源的基础记录；不得以肝脏或胰腺补充来源反向取代胃、十二指肠或食管基础来源。
